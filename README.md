# 豆角桌面伴侣（Doujiao Desktop）

豆角是一款正在开发中的 Windows 真人桌面伴侣。她可以在桌面上待机、响应对话、展示语音状态和任务信息，并通过不同人物场景陪伴用户工作。

## 当前状态

豆角的本机开发版已经完成桌面人物、语音对话、粒子语音球、任务光幕、场景切换和异常恢复等核心能力。

面向普通用户的独立 Windows 版正在开发中。公开版将免费使用，不要求购买、安装或配置 Wallpaper Engine，最终只提供一个“豆角”安装入口。

目前本仓库仅作为官方项目主页和开发进度记录，暂未提供安装包或源代码下载。请不要从非官方渠道下载名称相同的程序。

## 已有能力

- 真人桌面人物待机与场景切换
- 语音对话和文字对话测试
- 蓝色用户语音、黄色豆角回复的粒子语音球
- 桌面任务光幕和本地教学能力
- 桌面图标互动与安全恢复
- 运行状态检查、异常恢复和开机恢复

部分能力仍在本机开发环境中验证，以上列表不代表已经形成可公开安装的正式版本。

## 独立版路线

1. 使用豆角自己的 Windows 桌面宿主承载现有网页渲染与控制逻辑。
2. 将控制后台、运行依赖和必要素材整理成统一安装包。
3. 完成 Windows 10/11、不同 DPI、多显示器、全屏暂停与恢复测试。
4. 完成异常恢复、开机启动、升级和完整卸载测试。
5. 开放少量免费内测，再根据真实使用反馈发布正式体验版。
6. 完成代码、人物素材、声音、模型和第三方依赖的许可清理后，再决定源码开放范围。

## 下载说明

当前没有官方安装包。第一个可下载版本必须同时满足：

- 无需 Steam 或 Wallpaper Engine
- 一个安装包完成安装
- 一个“豆角”入口完成启动、设置和退出
- 在干净的 Windows 10/11 电脑上通过安装与卸载验证
- 人物、语音、任务显示、多显示器和异常恢复均可正常工作

达到这些条件后，安装包会通过本仓库的 Releases 页面发布。
