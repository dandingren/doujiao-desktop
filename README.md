# 豆角桌面伴侣（Doujiao Desktop）

豆角是一款正在开发中的 Windows 真人桌面伴侣。她可以在桌面上待机、响应对话、显示语音状态和任务进度，并通过人物动作与桌面图标互动。

## 最新进展

2026-09-13，首个免费独立 Windows 版候选包已在开发机完成实际安装和完整演示。它使用豆角自己的桌面宿主运行，不要求安装 Steam 或 Wallpaper Engine。

当前候选包只保留两套公开模组：

- 桌前对话：工作待机、靠近聆听、语音回复、实时口型、粒子语音球和任务光幕。
- 桌面图标互动：敲击屏幕、图标坠落与收纳、隐藏期间继续对话、恢复图标并回到工作状态。

## 实机演示

[![豆角免费独立桌面版实机演示](media/doujiao-free-desktop-beta-demo-poster-20260913.jpg)](media/doujiao-free-desktop-beta-demo-20260913.mp4)

[打开 90 秒完整演示视频](media/doujiao-free-desktop-beta-demo-20260913.mp4)

这段视频是 1920×1080 全桌面实录。为了让动作可以稳定复现，本次采用文字指令触发，不把它包装成真人麦克风识别演示。录制只保留豆角的程序声音，没有使用麦克风。

演示顺序：

1. 桌面待机、任务光幕和蓝色粒子语音球。
2. 人物靠近，以黄色语音球、字幕、TTS 和实时口型回复。
3. 敲击屏幕后，桌面图标坠落并被收起。
4. 图标隐藏时继续询问时间。
5. 恢复桌面图标，人物返回工作状态。

## 下载状态

目前暂不提供公开安装包。候选包已经通过本机安装和完整运行，但公开下载前仍需要完成：

- 对本次图标互动整段进行最终人工观感确认。
- 在干净的 Windows 10/11 电脑上测试安装、启动、覆盖升级和卸载。
- 补测不同 DPI、多显示器、全屏暂停与恢复。
- 为安装程序完成可信签名，减少 Windows 安全提示。
- 完成所有将公开文件的许可证和隐私清理。

完成这些门槛后，免费体验版会从本仓库的 Releases 页面提供。请不要从非官方渠道下载名称相同的程序。
