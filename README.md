# 豆角桌面伴侣（Doujiao Desktop）

豆角是一款正在开发中的 Windows 真人桌面伴侣。她可以在桌面上待机、响应对话、显示语音状态和任务进度，并通过人物动作与桌面图标互动。

## 最新进展

2026-09-14，免费独立 Windows 版已加入启动自检。它使用豆角自己的桌面宿主运行，不要求安装 Steam 或 Wallpaper Engine。

当前候选包只保留两套公开模组：

- 桌前对话：工作待机、靠近聆听、语音回复、实时口型、粒子语音球和任务光幕。
- 桌面图标互动：敲击屏幕、图标坠落与收纳、隐藏期间继续对话、恢复图标并回到工作状态。

[打开 90 秒完整演示视频](media/doujiao-free-desktop-beta-demo-20260913.mp4)

这段视频是 1920×1080 全桌面实录。为了让动作可以稳定复现，本次采用文字指令触发，不把它包装成真人麦克风识别演示。录制只保留豆角的程序声音，没有使用麦克风。

演示顺序：

1. 桌面待机、任务光幕和蓝色粒子语音球。
2. 人物靠近，以黄色语音球、字幕、TTS 和实时口型回复。
3. 敲击屏幕后，桌面图标坠落并被收起。
4. 图标隐藏时继续询问时间。
5. 恢复桌面图标，人物返回工作状态。

## 下载

[下载豆角 Windows 启动诊断测试版 0.1.0-alpha.3](https://github.com/dandingren/doujiao-desktop/releases/tag/v0.1.0-alpha.3)

这是预发布测试版，用于验证另一台 Windows 电脑上的安装、启动、桌面显示、对话、图标互动和卸载。下载 ZIP 后必须完整解压，再双击“安装豆角免费桌面版.exe”；安装程序和 `payload` 文件夹需要保持在同一目录。

0.1.0-alpha.3 去掉了可能卡住的 Windows 旧进程系统查询，并将桌面宿主阶段、进程号、WebView2 状态和宿主错误直接显示在“运行检查”。真正阻止启动的错误会置顶；因主故障尚未执行的步骤显示为“未检查”，图标控制显示为可选能力，媒体审计显示为开发质量记录。详细报告保存到 `%LOCALAPPDATA%\Doujiao\diagnostics\startup-latest.txt`。

安装包不包含开发机 API 密钥、账号配置、个人路径或桌面图标。联网对话需要在目标电脑的豆角设置页单独填写 API 配置。

当前仍需继续验证：

- 干净 Windows 10/11、不同 DPI、多显示器、覆盖安装和完整卸载。
- 安装程序数字签名。
- 图标互动整段与后续媒体的最终人工观感。

## 验证结果

- 安装目录文件边界检查：172 个文件，未包含教学、候选情绪素材、女仆、教师、API 密钥或开发机桌面图标。
- 自动检查：控制程序 138 项中 137 项通过、1 项需真实 Windows 桌面而跳过；渲染器 215 项全部通过。
- 启动失败会保留准确阶段、错误文字和本机诊断报告，不再只显示笼统的 90 秒请求超时。
- 独立宿主实机：人物、任务光幕、语音球、P13A 实时口型、图标收纳与恢复完整运行。
- 演示成片：90 秒、1920×1080、30fps、单一桌面声音轨。

更具体的边界和待办见 [公开状态说明](docs/RELEASE_STATUS.md)。
