# 豆角桌面伴侣（Doujiao Desktop）

豆角是一款正在开发中的 Windows 真人桌面伴侣。她可以在桌面上待机、响应对话、显示语音状态和任务进度，并通过人物动作与桌面图标互动。

## 最新进展

2026-09-14，免费独立 Windows 版已加入启动自检、内置音频组件和运行时卡点诊断。它使用豆角自己的桌面宿主运行，不要求安装 Steam 或 Wallpaper Engine。

当前候选包只保留两套公开模组：

- 桌前对话：工作待机、靠近聆听、语音回复、实时口型、粒子语音球和任务光幕。
- 桌面图标互动：敲击屏幕、图标坠落与收纳、隐藏期间继续对话、恢复图标并回到工作状态。

演示顺序：

## 下载

[下载豆角 Windows 音频与自诊断测试版 0.1.0-alpha.3](https://github.com/dandingren/doujiao-desktop/releases/tag/v0.1.0-alpha.3)

这是预发布测试版，用于验证另一台 Windows 电脑上的安装、启动、桌面显示、对话、图标互动和卸载。下载 ZIP 后必须完整解压，再双击“安装豆角免费桌面版.exe”；安装程序和 `payload` 文件夹需要保持在同一目录。

0.1.0-alpha.3 去掉了可能卡住的 Windows 旧进程系统查询，并将桌面宿主阶段、进程号、WebView2 状态和宿主错误直接显示在“运行检查”。控制中心和桌面人物使用两个独立的单实例锁；旧桌面人物仍在运行时会立即报告“桌面人物单实例冲突”，不再等待 75 秒。保存 API Key 后会自动重启语音服务并使用新配置；人物已进入播放状态且口型轨已就绪时会直接开始播报，不再等待缺失的事件而误报超时。桌面模式还加入了语音球原生拖动层。

本版内置 FFmpeg，不再要求目标电脑自行安装。语音设置会读取当前电脑的麦克风，原保存设备不存在时自动改用当前检测到的第一支麦克风；可选择 4 种豆包音色，并决定豆包失败时是否允许 Windows 系统音色备用。运行检查会记录回复生成、音色准备、画面等待和实际开播耗时，显示屏幕刷新率与浏览器报告的丢帧。界面动画跟随 30/60/120/144 Hz 等系统刷新节奏，视频保留素材自身帧率。

桌面图标助手与控制中心并发读写 `lease.json` 时，短暂文件占用会自动重试，不再立即当成致命故障并恢复图标；只有连续 8 秒没有任何有效心跳才会安全恢复。“桌面图标已显示”现在会注明是手动显示、角落按钮/快捷键恢复、超时恢复还是控制中心心跳中断恢复。真正阻止启动的错误会置顶；因主故障尚未执行的步骤显示为“未检查”，图标控制显示为可选能力，媒体审计显示为开发质量记录。详细报告保存到 `%LOCALAPPDATA%\Doujiao\diagnostics\startup-latest.txt`。

若 Windows 安全策略禁止运行豆角的桌面图标控制脚本，图标隐藏会保持关闭并显示策略原因，但桌面人物和文字对话仍可继续启动。豆角不会自动降低目标电脑的 PowerShell 安全策略。

安装包不包含开发机 API 密钥、账号配置、个人路径或桌面图标。联网对话需要在目标电脑的豆角设置页单独填写 API 配置。

- 安装程序数字签名。
- 图标互动整段与后续媒体的最终人工观感。

## 验证结果

- 安装 ZIP 共 174 个文件，286,648,482 字节，未包含教学、候选素材、女仆、教师、API 密钥、开发机个人路径或开发机桌面图标。
- 自动检查：控制程序 139 项中 138 项通过、1 项需真实 Windows 桌面而跳过；渲染器 216 项全部通过；Windows 原生隔离窗口 25 项全部通过。
- 隔离覆盖安装成功；安装后的内置 FFmpeg 9.0.1 检测到本机麦克风，音频设置接口返回 4 种音色且没有返回 API Key；真实 TTS 音频包络可由内置组件解析。
- LEASE 并发读写采用共享读取、短时重试和最后有效心跳宽限，一次文件占用不会触发恢复图标。
- 运行检查包含音画阶段耗时、刷新率和视频丢帧；桌面语音球仍使用独立原生拖动层。
- 启动失败会保留准确阶段、错误文字和本机诊断报告，不再只显示笼统的 90 秒请求超时。
- 独立宿主实机：人物、任务光幕、语音球、P13A 实时口型、图标收纳与恢复完整运行。
- 演示成片：90 秒、1920×1080、30fps、单一桌面声音轨。
