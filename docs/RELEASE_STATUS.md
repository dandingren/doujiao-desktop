# 公开版本状态

更新时间：2026-09-13

## 已完成

- 免费独立 Windows 桌面宿主，无需 Steam 或 Wallpaper Engine。
- 单一“豆角”入口负责启动、设置、状态查看和退出。
- 桌前对话与桌面图标互动两套公开模组已接入。
- 目标电脑的桌面图标在本机读取，本机清单不上传，也不携带开发机图标素材。
- API 密钥保存在当前 Windows 用户目录，不写入公开包、项目文件或浏览器存储。
- 开发机安装、运行、图标隐藏和恢复、TTS、口型、任务光幕、语音球已经实际走通。

## 尚未作为公开下载发布

- 安装程序尚未完成数字签名。
- 图标互动整段仍等待项目所有者看完演示后的最终观感确认。
- 干净 Windows 10/11、不同 DPI、多显示器、覆盖升级和完整卸载矩阵尚未完成。
- 源代码、人物素材、视频素材和第三方组件仍在做逐项许可清理。

这些项目完成前，本仓库只发布演示和状态说明，不发布安装包，也不把本机研发功能列为公开成品功能。

- 不代表真人麦克风识别、干净电脑安装或多显示器兼容性已经通过公开验收。
