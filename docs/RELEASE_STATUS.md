# 公开版本状态

更新时间：2026-09-14

## 已完成

- 免费独立 Windows 桌面宿主，无需 Steam 或 Wallpaper Engine。
- 单一“豆角”入口负责启动、设置、状态查看和退出。
- 桌前对话与桌面图标互动两套公开模组已接入。
- 目标电脑的桌面图标在本机读取，本机清单不上传，也不携带开发机图标素材。
- API 密钥保存在当前 Windows 用户目录，不写入公开包、项目文件或浏览器存储。
- 开发机安装、运行、图标隐藏和恢复、TTS、口型、任务光幕、语音球已经实际走通。
- 启动器会逐步检查安装文件、写入权限、WebView2、端口、桌面宿主、桌面层、语音和常驻服务；失败时保存本机诊断报告。

## 当前公开测试版

- 当前准备发布预发布版 `v0.1.0-alpha.3`，安装 ZIP 为 286,648,482 字节。
- 安装 ZIP 共 174 个文件，不包含 API 密钥、账号配置、个人路径、开发机桌面图标或未批准的候选视频。
- ZIP SHA-256：`B3DB11EF4163D7EC3C85031103520E6C8779B21C76E565504B34A52BC96F0064`。
- 去掉了可能卡住的 Windows 旧进程系统查询；启动窗口和“运行检查”会显示桌面宿主阶段、进程号、WebView2 状态、宿主错误和报告路径。
- 控制中心与桌面人物使用不同的单实例锁；旧桌面人物占用锁时立即显示冲突原因和本机报告，不再静默退出后等待 75 秒。
- “运行检查”把主故障置顶；其余项目按通过、错误、未检查、可选和信息分级，媒体开发审计不再误报为安装者必须处理的启动错误。
- Windows 策略禁止图标控制脚本时只停用图标隐藏，不阻塞桌面人物和文字对话；安装包不会自动修改目标电脑的 PowerShell 安全策略。
- 保存 API Key 后会立即重启语音服务；自动、轻量和高精度模式会在新进程中重新读取当前 Windows 用户的配置。
- 播报就绪同时接受渲染器的当前播放状态和口型轨回执，不再依赖可能缺失的 `state-started` 事件。
- 桌面模式增加独立的透明拖动层，让嵌入桌面图标后方的语音球仍可用鼠标拖动；运行检查会单独显示拖动层是否就绪。
- 安装包内置 FFmpeg 9.0.1，自动枚举目标电脑麦克风；原保存设备不存在时使用当前检测到的第一支麦克风。
- 设置页提供 4 种豆包音色和 Windows 音色备用开关；保存后重启语音服务，不把配置写入发布包。
- LEASE 文件并发读写使用共享读取、短时重试和最后有效心跳宽限；一次文件占用不再触发恢复图标。
- 运行检查记录回复、音色、画面和开播耗时，测量显示器刷新节奏，并显示真实视频总帧、丢帧和比例。
- 隔离覆盖安装通过；控制程序 139 项中 138 项通过、1 项跳过，渲染器 216 项通过，Windows 原生隔离窗口 25 项通过。
