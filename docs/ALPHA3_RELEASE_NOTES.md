# 豆角 Windows 0.1.0-alpha.3

这是用于另一台 Windows 电脑安装验证的预发布测试版。下载 ZIP 后请完整解压，再双击“安装豆角免费桌面版.exe”。安装程序与 `payload` 文件夹必须保持在同一目录。

本版修复控制中心占用单实例锁导致桌面人物等待 75 秒的问题，并在启动失败时直接显示卡住阶段、桌面宿主错误和本机诊断报告路径。保存 API Key 后会自动重启语音服务；人物画面和口型就绪后直接播报。

新增内置 FFmpeg、目标电脑麦克风自动枚举、4 种豆包音色选择和 Windows 音色备用开关。运行检查会记录回复生成、音色准备、画面等待和实际开播耗时，显示屏幕刷新率与视频丢帧。首次合成新句可能需要联网等待，重复句命中本机语音缓存后会更快。

桌面图标助手与控制中心同时读写 LEASE 文件时，短暂占用会自动重试；只有连续 8 秒无有效心跳才安全恢复图标。“桌面图标已显示”会注明手动显示或自动恢复原因。语音球增加独立原生拖动层。

若目标电脑的 Windows 安全策略禁止运行桌面图标控制脚本，本版会保持图标隐藏功能关闭并显示原因，不会自动修改安全策略；桌面人物和文字对话仍可继续使用。

验证：控制程序 139 项中 138 项通过、1 项跳过；渲染器 216 项全部通过；Windows 原生隔离窗口 25 项全部通过；隔离覆盖安装、内置 FFmpeg、麦克风枚举、音频包络和无密钥返回检查通过。
